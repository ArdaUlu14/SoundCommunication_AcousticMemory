# Acoustic Memory

**Acoustic Memory** is an interactive, audio-reactive WebGL installation that maps live microphone inputs across a dynamic radial data matrix. 

## 📌 Features

*   **Real-Time Audio Analysis:** Captures and processes live microphone data to instantly drive visual elements.
*   **Radial Data Matrix:** Maps audio frequencies and amplitudes onto an aesthetic, geometric circular plane.
*   **Fluid WebGL Performance:** Delivers a smooth, high-performance browser-based visual experience.

## 📂 Project Structure & Documentation

The repository includes the core visualization files along with the project's conceptual documentation:

*   `sound.html`: The main interactive visualization interface and WebGL render canvas.
*   `AcousticMemoryReport.pdf`: Details the theoretical background, research methodology, and core concept of the installation.
*   `AcousticMemoryVisualizationPresentation.pdf`: Outlines the design decisions, layout parameters, and the radial matrix framework.
